# Branding – TR2013 HUD Fix+

Release graphics for Nexus Mods and GitHub. Everything is generated by `tools/generate.py`; do not edit the SVGs by hand.

## Files

| File | Use |
|---|---|
| `graphics/tr2013-hudfix_nexus_1920x1080.png` / `.svg` | Nexus title image (16:9) |
| `graphics/tr2013-hudfix_github_1280x640.png` / `.svg` | GitHub social preview (Settings → Social preview) |
| `graphics/tr2013-hudfix_icon_512.png` / `.svg` | Icon / avatar |
| `graphics/tr2013-hudfix_compare_TEMPLATE.png` / `.svg` | Layout template for before/after comparisons |

Nexus and GitHub only accept raster images → upload the **PNGs**. The SVGs embed the font, so they render identically everywhere.

## Content rules

- **No feature list on the graphics.** Only: name, subtitle, version line, "Unofficial community mod", legal notice.
  If features are ever shown, only released ones: `HUD Fix · In-game menu · FPS limiter`.
  Planned items (console-style safe zone, HUD scaling, per-element HUD customization) belong in the Nexus description under "Roadmap / Work in progress" — never on the graphics.
- **No mod version number** (e.g. 1.4.1) on the graphics, so they stay valid across updates.
- No official Tomb Raider logo, no original game font, no Lara Croft, nothing that looks official.
- Red accent (`#9e1c3a`, sampled from the in-game `[KEY]` prompts) only for the "[UNOFFICIAL COMMUNITY MOD]" text, the side tab, and the logo underline. **No red "+"** (avoid Red Cross associations).
- Icon: no version info, just logo + "HUD FIX+".

## Updating after a game patch

In `tools/generate.py`, edit only these two constants:

```python
VERSION = "FOR THE CURRENT PC VERSION  ·  PATCH 838  ·  STEAM &amp; EPIC"
BUILD = "STEAM BUILD 9573671"
```

Then regenerate:

```bash
pip install fonttools brotli numpy matplotlib
cd branding/tools
python generate.py                      # writes all SVGs to ../graphics
```

Render PNGs (needs Chrome/Chromium):

```bash
./render.sh ../graphics/tr2013-hudfix_nexus_1920x1080.svg ../graphics/tr2013-hudfix_nexus_1920x1080.png 1920 1080
./render.sh ../graphics/tr2013-hudfix_github_1280x640.svg ../graphics/tr2013-hudfix_github_1280x640.png 1280 640
./render.sh ../graphics/tr2013-hudfix_icon_512.svg       ../graphics/tr2013-hudfix_icon_512.png       512 512
```

On Windows without bash: `chrome.exe --headless=new --hide-scrollbars --window-size=1920,1080 --screenshot=out.png file:///E:/…/file.svg`, or open the SVG in a browser / Inkscape and export.

## Before/after comparisons

```bash
python generate.py compare before.jpg after.jpg "Caption" tr2013-hudfix_compare_<name>
```

Creates `graphics/tr2013-hudfix_compare_<name>.svg` (screenshots embedded) → render to 1920×1080 PNG as above.
Only use pairs that show **released** improvements. No screenshots containing the official game logo (e.g. the pause menu with the fix off).

## Design / technical

- Look based on the in-game HUD: crisp white strips with black text (notifications), black boxes (objectives), map backdrop with contour lines, crosshair, ragged dark edges.
- Logo: four safe-zone corner brackets around a white "H+" badge with a cut corner and a crimson underline.
- Font: Barlow Semi Condensed 500/600/700 (SIL Open Font License, see `tools/fonts/OFL-LICENSE.txt`), embedded in the SVGs as base64.
- Randomness (scratches, contour lines) uses fixed seeds → regenerating produces identical images.
